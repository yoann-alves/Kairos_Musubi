# The most important lesson

Since I finished [RareCode](https://rarecode.ai/), for about a week I struggled a lot. I was wondering: "What's next?".

I've tried to:

- read a book ([Learn Rust in a Month of Lunches](https://www.manning.com/books/learn-rust-in-a-month-of-lunches)) that I've already talked about, and it was really valuable until the chapter covered a topic that I haven't previously understood and practiced.
- follow tutorials, but it was really short because I just don't like that.
- start a personal project with [Leptos](https://leptos.dev/), well… my skills need some improvements before Leptos. I didn't understand a lot of things while going through the documentation.

My attempt to create a personal project was maybe a little bit too rushed. But because of that I've found [Codewars](https://www.codewars.com/), did a lot of kata (all the 8 kyu in Rust) and progressed **a lot**.

So what's the lesson here?

I can summarize it in one single word: **PRACTICE**.

You probably know the famous proverb: "Practice makes perfect".
In my experience, it's more something like: "Practice makes progress".
If you chase perfection, you'll be stuck even before the starting line.

Practice, that's the most important word that's related to progress, not just in code but everywhere.

# Become an expert

I'm not an expert. Absolutely not. Keep that in mind.

I've done some research with this single question in mind: "How can I improve my Rust skill without a limit?", all I want is to keep learning Rust for a very long time, and always learn something new.

This is very close to the question: "How to learn?".

In summary, all I want is to learn like an expert in learning. Something like that.

I've always loved learning new things. Like you I'm sure of that.

But because I've only one life (which could stop at any time btw) and only 24h/day, I think spending a little bit of time here and there to learn how great learners learn, and copy them is worth the time.

I'm talking about learning and how to become an expert because, first I want to improve in these areas, and second because this is the next part that comes right after **PRACTICE**.

Yes we have to practice to get better at what we are doing, but learning the meta skill of learning to be even better isn't an option to reach the top.

"Work smart, not hard". I don't like this quote. Yes I want to work hard because I love it, because I have no other choice to achieve my dreams. You can work hard and smart. Why not!.

# What's next for me

When I discovered [Codewars](https://www.codewars.com), I've set myself the goal to complete all the kata in Rust (1185 right now). I already completed 148 (all the 8 kyu), and improved a lot with iterator and collections in Rust, but also in logic (which I was aiming for).

That goal isn't going anywhere, but I'll still modify it a little. Before I wanted to complete all the kata and then start some personal project.

After my research on learning, I now think that is not the better way for me to progress. The real goal isn't to complete all the Codewars's kata, it's to create projects, build stuff. So, I'll build some cool stuff and alongside complete the kata that are related to the problems/concepts that I want to learn. These problems and concepts will appear to me in my project.

The idea isn't anymore learning by following a premade path, but learning because I need to, to solve my current problem in my project.

## My project

There is one thing that annoys me a ~~little~~ lot with Rust, and that is finding resources.

I'm learning Rust, and the more I learn Rust the more I love it. So I want to learn even more…

The Rust community is incredible, a lot of people create content inside/for the community, like crate, videos, books, articles, documentations, tools, etc.

Some "resources" are easy to find. If I tell you about [Jon Gjengset](https://thesquareplanet.com), you know him, you just can't miss him in the Rust ecosystem, same for [The Book](https://doc.rust-lang.org/book/). Another example, even a beginner like me now knows some famous crate (even without the required level to use it) like [tokio](https://docs.rs/tokio/latest/tokio/) or [serde](https://docs.rs/serde/latest/serde/).

But what if you have a very specific need?

I don't want to create this project for me or for beginners but for the community. The expert in embedded devices that might need something very specific, the intermediate in Rust who wants to learn Web3, the beginner in code (hey that's me) that probably needs to review the same thing 91422945495734957 times before it finally makes sense.

Rust is such an amazing language, the community is awesome, I love both of them. So I want to create something right now that can help you and me, find the resources that we are looking for.

I can't build an amazing thing with just 1 month in the coding area. But by working hard, I can surely create something that works even if it's not as beautiful as [that website](https://www.flyward.com/).

If you don't have yet guessed what's my project, it's just a DB that stores Rust's resources.

The idea at the beginning is that the community can add some resources (with a description, some tags, and the link will also be useful), and then the community can up vote or down vote the resource, submit improvement in the description and leave comments.

The idea is just to have a place to find something that you need without digging for hours and ending with nothing.

I will stream on Twitch and YouTube everything that I build and the project will be open source.

And of course, it will take a long time before this solution really helps you. I can't add all the resources alone, and also, as a beginner knowing if X resource is bad or not is impossible. That's why it will take a long time. I need the more people possible to just add resources, vote for it to have better search results, to comment and suggest improvement for the description/how to use well the resource.

I have great ambitions with this project. It will take years but it's worth to try.

### The final idea and why

The vision:
Everyone can learn Rust for free, from my grandmother, to the tech team of a billion dollars company.

That means from the complete beginner in code, to a team that know how do the works in production. They can all learn something to be better.

The beginner in code is the starting line that show the whole idea. From beginner to a specialist in a chosen domain that get hire by a company, for free.

Why:
I love to learn and to teach things. So at first I thought to create a business around teaching Rust (when I'll have the level required).

But after, coding every day for hours, and love more and more Rust, I change my mind.

I'll take JS in example because I know a little bit about that language. For JS there are tons of online courses and bootcamps. People do that because it print money (if really good). In some way I feel that do something bad to JS, I like online courses/I'm not against it, but it feel wrong to me to have that.

The thing is, it's possible to learn JS for free. But online courses still exists because provide the experience that the teacher have.

For Rust we don't have that (yet). Some things exists, but there aren't many.

Think about that: what if, for free, everyone can learn from 0 Rust and become an expert that big company want to hire (like really want you). Provide something that's so good for free that every online courses can't even exist. And most important, if you don't have much money, with hard work and enough time, you'll change your life.

And here you should think, that's a dream, and you're right. That doesn't mean that I'll give up on that.

I'll finish on that point. Think about what looks like the Rust ecosystem with that vision.

In my opinion, everyone will benefit from that (more programmer, more projects, more company that use Rust, better programmer…)
